# Selection

Choosing one or more options from a set: on/off, pick-one, pick-many.

| Name | Also called | What it is | Use when | Avoid when | Variants/states | Web (HTML/ARIA, shadcn/Radix) | iOS (SwiftUI) | Android (Compose/Material) | Alternatives |
|---|---|---|---|---|---|---|---|---|---|
| Checkbox | Check control | Independent binary control, usually one of several in a group | Multiple independent yes/no choices, or a single required agreement | Mutually exclusive options (use radio) | Checked, unchecked, indeterminate, disabled | `<input type=checkbox>`; shadcn `Checkbox` (Radix) | `Toggle(.checkbox)` (rare on iOS) | `Checkbox`/`TriStateCheckbox` (M3) | Switch (for settings), chip group (multi-select) |
| Radio group | Radio buttons | Set of mutually exclusive options, one selectable at a time | Small set (2–5) of exclusive choices, all visible at once | Single on/off (use switch), or large option set (use select) | Vertical/horizontal layout, card-style radios | `<input type=radio>` group; shadcn `RadioGroup` (Radix) | `Picker(.inline)` | `RadioButton` group (M3) | Segmented control, select, toggle group |
| Switch | Toggle, on/off switch | Binary control representing an immediate state change (not a form submit) | Settings that take effect immediately (Wi-Fi on/off, dark mode) | Choices needing explicit form submission (use checkbox) | On/off, with label, disabled, loading | `role=switch`; shadcn `Switch` (Radix) | `Toggle` | `Switch` (M3) | Checkbox, segmented control (2-option) |
| Toggle button | Pressed button, icon toggle | Single button with a pressed/unpressed boolean state | Standalone binary action shown as a button (bold, mute, favorite) | Part of a multi-option group (use toggle group) | Icon-only, with label, pressed styling | `aria-pressed`; shadcn `Toggle` (Radix) | `Button` + `.toggleStyle` | `IconToggleButton`, `FilterChip(selected)` | Checkbox, icon button with state |
| Toggle group | Button group (multi-select toggle) | Set of toggle buttons allowing single- or multi-select | Compact exclusive/inclusive choice among icons or short labels | Long labels or many options | Single-select vs. multi-select mode | shadcn `ToggleGroup` (Radix) | Custom `HStack` of toggle `Button`s | `MultiChoiceSegmentedButtonRow` (M3) | Segmented control, chip group, checkbox group |
| Segmented control | Segmented button | Compact set of mutually exclusive buttons in one track | 2–5 tightly related exclusive options in constrained space | Independent (non-exclusive) options | Icon-only, text, icon+text | `role=radiogroup`; shadcn `ToggleGroup` (single mode) | `Picker(.segmented)` | `SingleChoiceSegmentedButtonRow` (M3) | Radio group, tabs, dropdown |
| Chip | Tag (display) | Small, rounded, compact element representing an attribute, filter, or input token | Labeling, filtering, or compact multi-value display | Primary actions (use a button instead) | Input, choice, filter, assist chip (M3 naming) | `<span>`/`<button>`; shadcn `Badge`/custom chip | Custom capsule `Button`/`Label` | `AssistChip`/`FilterChip`/`InputChip`/`SuggestionChip` (M3) | Tag input, toggle button |
| Filter chip | Filter tag | Chip that toggles a filter on/off, often shown selected/unselected | Faceted filtering over a list/grid of results | Filters that need a form-style commit step (use a filter panel) | Single-select or multi-select row, with count badge | Custom chip + `aria-pressed` | Custom toggle `Button` capsule | `FilterChip` (M3) | Checkbox list in a panel, segmented control |
| Listbox | List selection, selectable list | List where one or more rows are selectable, distinct from a menu (no action-firing) | Selecting from a visible list of items (contacts, files) | Triggering actions (use a menu) | Single/multi-select, with checkboxes, virtualized | `role=listbox`/`option`; shadcn `Command`/`Select` internals | `List(selection:)` | `LazyColumn` + selectable `ListItem` | Table with row selection, combobox |
| Multi-select | Multiselect combobox, multi-select dropdown | Combobox/select variant allowing multiple chosen values, shown as chips | Choosing several items from a moderate/large set | Only one value can ever be chosen | Chips-in-field, dropdown checklist, "select all" | Custom (Radix `Select` has no native multi); shadcn multi-select patterns | Custom `List` with checkmarks | Custom `ExposedDropdownMenuBox` + checkable items | Chip group, transfer list, checkbox list |
| Transfer list | Dual listbox, shuttle control | Two listboxes with controls to move items between "available" and "selected" | Assigning many items to a set with a clear included/excluded distinction | Small option counts (a checklist is simpler) | Single vs. multi-item move, search-filter each side | Custom (no native el.); ARIA two listboxes + buttons | Custom two-`List` layout | Custom two-`LazyColumn` layout | Multi-select dropdown, drag-and-drop reordering |
| Card selection | Selectable card, radio card | Card-shaped container acting as a large touch target for one option in a set | Options that need an image/description, not just a label (plan tiers, product variants) | Simple short-label choices (use radio/segmented) | Single-select (radio card) or multi-select (checkbox card) | `<label>` wrapping `<input>` + card styling | `Button` styled as card + selection state | `Card` + `selected` state (M3) | Radio group, chip group |
| Swatch selector | Color/pattern swatch picker | Grid of small fixed color/pattern samples, one selectable | Choosing from a small fixed palette (theme, product color) | Open-ended color choice (use color picker) | Grid, circular vs. square swatches | Custom `role=radiogroup` of swatches | Custom `LazyVGrid` of tappable circles | Custom `LazyVerticalGrid` | Color picker, dropdown select |
| Icon picker | Icon selector grid | Grid of icon options where one is chosen, similar to a swatch selector but for icons | Letting a user assign an icon to a category/item (folder icon, emoji-style tag) | Icon set is large enough to need search (add a search field on top) | Grid, categorized tabs, searchable | Custom `role=radiogroup` grid | Custom `LazyVGrid` of icon buttons | Custom `LazyVerticalGrid` of icon buttons | Emoji picker, color swatch selector |
