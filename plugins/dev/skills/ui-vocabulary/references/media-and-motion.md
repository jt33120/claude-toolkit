# Media & motion

Displaying visual/media content, plus the vocabulary for animation and
gesture. Motion timing/style choices always follow the project's own motion
system — the terms below are for naming, not for prescribing a feel.

| Name | Also called | What it is | Use when | Avoid when | Variants/states | Web (HTML/ARIA, shadcn/Radix) | iOS (SwiftUI) | Android (Compose/Material) | Alternatives |
|---|---|---|---|---|---|---|---|---|---|
| Image | — | Static raster/vector visual content | Photos, illustrations, icons rendered from a file | — | Responsive/`srcset`, lazy-loaded, with fallback/alt | `<img>`, `<picture>` | `Image`, `AsyncImage` | `Image`, Coil/Glide async loading | — |
| Video player | Media player | Control set for playing video (play/pause, scrub, volume, fullscreen) | Embedded or full video playback | — | Native controls vs. custom-skinned, inline vs. fullscreen, captions | `<video>` + controls; custom players | `VideoPlayer` (AVKit) | `VideoView`/ExoPlayer-based player | Autoplaying looped clip ("cinemagraph"), GIF |
| Gallery | Image gallery, media grid | Grid or grouped display of multiple images/media items | Browsing a set of photos/media | Single hero image (just use an image) | Grid, justified/masonry layout, tap-to-lightbox | Custom grid + lightbox | `LazyVGrid` of thumbnails | `LazyVerticalGrid` of thumbnails | Carousel, masonry |
| Icon | Iconography, glyph | Small symbolic graphic representing an action/concept/category | Compact, universally-recognizable representation alongside or instead of text | The symbol isn't broadly recognizable (pair with a label) | Outline vs. filled, size scale, monochrome vs. multicolor | SVG/icon font; Lucide/Radix Icons (shadcn default) | SF Symbols | Material Symbols/Icons | Text label, illustration |
| Illustration | Spot illustration, hero art | Larger decorative or explanatory drawn/graphic artwork | Empty states, onboarding, marketing sections needing warmth/story | Dense functional UI (adds no information) | Spot (small, contextual) vs. hero (large, page-level) | `<img>`/inline SVG | `Image` (asset) | `Image` (drawable/vector asset) | Icon (for functional contexts), photo |
| Transition | Screen transition, page transition | Animated change from one view/state to another | Any navigation or state change benefiting from continuity cues | Rapid repeated actions where animation adds latency-feel | Push/pop, fade, slide, cross-dissolve | CSS transitions, View Transitions API | `NavigationStack` push/pop, `.transition()` | `Modifier` + Compose animation APIs, Navigation transitions | Instant/no-animation change |
| Shared element transition | Matched geometry transition, hero animation | Animation where an element morphs/flies from its position in one view to its position in the next | Connecting a thumbnail to its detail view, list item to expanded card | Elements with no visual counterpart in the destination view | Position+size morph, with cross-fade of surrounding content | View Transitions API (`view-transition-name`) | `matchedGeometryEffect` | Compose `SharedTransitionLayout` | Plain cross-fade, slide transition |
| Micro-interaction | Micro-animation | Small, localized animated feedback for a single action (button press, toggle flip, like) | Reinforcing that an action registered, adding tactile feel | Overused across unrelated elements (creates noise) | Scale/bounce on tap, icon morph, haptic pairing | CSS transitions/keyframes | `.animation()` modifier, `SFSymbol` animations | Compose `animate*AsState` | Static state change (no animation) |
| Parallax scrolling | Parallax effect | Background/foreground layers moving at different rates while scrolling | Depth/immersion in hero sections or storytelling pages | Content-dense/functional screens (can hurt readability, motion sickness) | Layered depth, scroll-linked transforms | CSS `background-attachment`/scroll-linked JS | `GeometryReader` + scroll offset | Compose scroll-linked `graphicsLayer` offset | Static background, simple fade-in on scroll |
| Spring animation | Physics-based animation | Animation driven by a spring physics model (mass/stiffness/damping) rather than a fixed duration curve | Natural-feeling, interruptible motion (drag-release, drawer snapping) | Motion needing exact, predictable timing (use an eased duration curve) | Bouncy vs. critically-damped (no overshoot) | CSS/JS spring libs (e.g. Framer Motion) | `.spring()`, `.interactiveSpring()` | Compose `spring()` AnimationSpec | Duration + easing curve |
| Easing curve | Timing function | A curve mapping animation progress over time (ease-in, ease-out, ease-in-out, linear) | Any fixed-duration animation needing a natural start/stop feel | Physically-driven/interruptible motion (use a spring instead) | Standard/emphasized/legacy easing sets (Material has named curves) | CSS `transition-timing-function`, `cubic-bezier()` | `.animation(.easeInOut)`, `Animation.timingCurve` | Compose `tween(easing:)` | Spring animation |
| Swipe gesture | Swipe-to-action | Horizontal/vertical drag gesture triggering navigation or a row action | Dismiss/delete/archive on a list row, back-navigation, carousel paging | Actions with high consequence and no confirmation/undo | Swipe-to-delete, swipe-to-reveal-actions, swipe-to-navigate | Touch/pointer events; libs for swipeable rows | `.swipeActions()` (List row) | `SwipeToDismiss`/`DismissibleItem` (Compose) | Visible action buttons, long-press menu |
| Pull-to-refresh | Pull-down-to-reload | Downward drag past a list's top edge triggers a data reload, with a spinner reveal | Refreshing feed/list content on demand, mobile-native feel | Desktop web (no native gesture expectation) | With haptic/elastic overscroll, custom refresh indicator | Custom (rare native pattern on web) | `.refreshable` | `PullToRefreshBox` (Compose) | Manual refresh button |
| Long press | Long-tap, press-and-hold | Gesture held past a threshold duration, typically revealing a context menu or entering a mode | Surfacing secondary actions without a dedicated visible control (touch equivalent of right-click) | Actions needing discoverability (long-press is inherently hidden) | With haptic feedback, progress-fill variant (hold-to-confirm) | `contextmenu`/long-press JS libs | `.onLongPressGesture`, `.contextMenu` | `Modifier.combinedClickable(onLongClick:)` | Visible overflow menu, swipe actions |
| Pinch-to-zoom | Pinch gesture | Two-finger gesture scaling content in/out | Zooming images, maps, canvases | Content with no meaningful zoom level (plain text pages) | With rotation gesture paired, double-tap-to-zoom shortcut | Touch events / CSS `touch-action` | `MagnificationGesture` | `Modifier.pointerInput` + `detectTransformGestures` | Explicit zoom +/− buttons, double-tap zoom |
| Haptic feedback | Tactile feedback, vibration feedback | Brief device vibration accompanying an interaction to reinforce it physically | Confirming taps, toggles, errors, or milestones on touch devices with haptic hardware | Desktop web (no haptic hardware), or overused until it feels noisy | Light/medium/heavy impact, success/warning/error notification patterns | Vibration API (limited support) | `UIImpactFeedbackGenerator`, `.sensoryFeedback()` | `HapticFeedback`/`View.performHapticFeedback` | Visual micro-interaction alone |
| Marquee / ticker | Scrolling text, news ticker | Text or content that scrolls continuously/loops horizontally within a fixed-width container | Overflowing content that should stay visible without truncation (song title, stock ticker) | Body content users need time to read carefully (motion hurts readability) | Continuous loop, pause-on-hover, bidirectional | CSS `animation` scroll loop (native `<marquee>` deprecated) | Custom `.offset` animated loop | Compose `basicMarquee()` modifier | Truncation with ellipsis + tooltip, static wrap |
