# Navigation

Moving a user between views, sections, or steps. Platform convention matters
a lot here — do not force a web pattern onto a native mobile app.

| Name | Also called | What it is | Use when | Avoid when | Variants/states | Web (HTML/ARIA, shadcn/Radix) | iOS (SwiftUI) | Android (Compose/Material) | Alternatives |
|---|---|---|---|---|---|---|---|---|---|
| Tabs | Tab list, tabbed panel | A row of labels that switch between sibling content panels in place | Few (2–6) parallel, same-level views the user compares or flips between | Content is sequential/dependent, or there are many sections | Underline, pill, boxed; icon+label; scrollable | `role=tablist/tab/tabpanel`; shadcn `Tabs` | `TabView`, `Picker(.segmented)` | `TabRow`, `PrimaryTabRow` (M3) | Segmented control, sidebar, accordion |
| Bottom navigation | Tab bar (iOS), bottom tab bar | Fixed bar of 3–5 top-level destinations at the screen bottom | Primary app sections on mobile | More than 5 destinations, or desktop web | Badges, active-state fill/label | Custom fixed nav (rare on web) | `TabView` (bottom style) | `NavigationBar` (M3) | Navigation drawer, hamburger menu |
| Navigation bar | App bar, top bar, header bar | Persistent top bar with title, back action, and page-level actions | Every screen needs a title/back/actions anchor | — | Large title, collapsing, search-embedded | `<header>`/`<nav>` | `NavigationStack` toolbar | `TopAppBar` (M3) | Breadcrumb, page header |
| Sidebar | Nav rail (collapsed), side nav | Persistent vertical list of sections, usually left-aligned | Many sections, desktop/tablet width, need-always-visible nav | Narrow viewport / mobile portrait | Collapsible, icon-only rail, nested tree | `<nav>` + list; shadcn `Sidebar` | `NavigationSplitView` sidebar | `NavigationRail`, `PermanentNavigationDrawer` | Bottom navigation, tabs, drawer |
| Navigation drawer | Hamburger menu, off-canvas menu | Panel that slides in (usually from the edge) holding nav links | Many/secondary destinations you don't want always visible | Primary destinations used every session | Modal (overlay) vs. standard (push content); left/right | `<dialog>`/aside + toggle | `.sheet`/custom side panel | `ModalNavigationDrawer`, `DismissibleNavigationDrawer` | Sidebar, bottom navigation |
| Breadcrumb | Breadcrumb trail | Horizontal trail showing the current page's location in a hierarchy | Deep hierarchical content (docs, file trees, e-commerce categories) | Flat or shallow (1–2 level) structures | Truncated/collapsed middle items, icons | `<nav aria-label="breadcrumb">`; shadcn `Breadcrumb` | Rare; custom label row | Rare; custom `Row` | Back button, path/title in app bar |
| Pagination | Page numbers, paged nav | Discrete controls to move between fixed pages of results | Users need to jump to/return to a specific position, or content is finite and indexed | Endless/social feeds, or unknown total length | Numbered, prev/next only, "load more" button | `<nav aria-label="pagination">`; shadcn `Pagination` | Custom control | Custom `Row` of buttons | Infinite scroll, "load more" button |
| Stepper (navigation) | Progress stepper, wizard steps | Ordered indicator of steps in a multi-step flow, often clickable | Linear multi-step process (checkout, setup) where progress matters | Single-step forms | Numbered, linear vs. non-linear, with labels | Custom (no native HTML el.); ARIA `aria-current="step"` | Custom `HStack` of steps | Custom `Row`; M3 has no built-in stepper | Progress bar, wizard, accordion form |
| Segmented control | Segmented button, toggle group (nav use) | Small set of mutually exclusive buttons acting as a view switch | 2–5 tightly related view/filter states, compact space | Independent (non-exclusive) options, or long labels | Icon-only, text, icon+text | `role=radiogroup` of buttons; shadcn `ToggleGroup` | `Picker(.segmented)` | `SingleChoiceSegmentedButtonRow` (M3) | Tabs, toggle group, dropdown |
| Command palette | Command menu, quick switcher, ⌘K menu | Keyboard-invoked searchable list of actions/destinations | Power-user shortcut across many actions/pages, desktop-first apps | Simple apps with few actions, touch-only context | Grouped results, recent items, fuzzy search | shadcn/cmdk `Command`; ARIA combobox pattern | Rare native equiv.; custom sheet | Rare native equiv.; custom dialog | Search field, menu bar, keyboard shortcuts list |
| Menu bar | App menu bar, top-level menu | Horizontal bar of dropdown menus (File, Edit, View…) | Desktop apps with many grouped commands | Mobile, or apps with few commands | Nested submenus, checkable items | Rare on web (browser owns menu bar) | macOS `.commands` (not iOS) | Rare (Android has no menu bar) | Overflow menu, command palette |
| Back button pattern | Back navigation, up button | Control that returns to the previous screen/state in a stack | Any pushed/drilled-down screen | Top of navigation stack, or tab roots | System back gesture, in-bar back arrow, "Up" vs. "Back" (Android distinguishes) | Browser back; in-page `<a>`/button | `NavigationStack` auto back button, swipe-back gesture | System back gesture/button, `NavigationBar` back arrow | Breadcrumb, close button (for modals, not stacks) |
| Overflow menu | "More" menu, kebab menu | Menu collapsing secondary actions behind a `⋮` or `•••` icon | Toolbar/app bar has more actions than fit | Only 1–2 actions total | Icon-triggered dropdown/menu | `<button>` + `role=menu`; shadcn `DropdownMenu` | `Menu` (toolbar) | `DropdownMenu` (M3), kebab `IconButton` | Action sheet, toolbar buttons, split button |
| Table of contents / anchor nav | Page outline, in-page nav | List of in-page anchors that scroll/jump to sections | Long single-page docs or articles | Short pages, multi-page apps | Sticky/floating, scrollspy-highlighted | `<nav>` of `<a href="#...">` | Rare; custom `List` | Rare; custom `LazyColumn` index | Breadcrumb, pagination (multi-page split) |
| Navigation rail | Rail nav | Slim, icon-only (or icon+label) vertical nav bar, a collapsed sidebar variant | Tablet/desktop widths where a full sidebar is too wide but bottom nav feels mobile-only | Narrow mobile portrait (use bottom navigation) | Icon+label vs. icon-only, expandable to full sidebar | Custom narrow `<nav>` column | `NavigationSplitView` compact sidebar | `NavigationRail` (M3) | Sidebar, bottom navigation |
| Megamenu | Mega dropdown | Large multi-column dropdown panel from a top nav item, showing many links/categories at once | Wide site navigation with many nested categories (e-commerce, large marketing sites) | Small link sets (use a plain dropdown menu) | Multi-column, with images/featured items | Custom `role=menu` panel | Rare on iOS (mobile favors drill-down) | Rare on Android (mobile favors drill-down) | Dropdown menu, drill-down navigation drawer |
| Skip link | Skip to content link | Visually hidden link, keyboard-focusable first, that jumps past repeated nav to main content | Any page with nav/header repeated across pages (accessibility requirement) | — | Visible-on-focus only | `<a href="#main">` first in DOM | N/A (no page-reload concept) | N/A (no page-reload concept) | Landmark regions (`<main>`, `role=main`) |
| Pill navigation | Pill tabs | Tab-like nav where the active item shows as a filled rounded "pill" background | Compact nav rows wanting a soft, capsule-style active indicator | — | Sliding pill animation, icon+label | Styled `Tabs`/`ToggleGroup` variant | Styled segmented `Picker` | Styled `TabRow`/`SegmentedButton` | Underline tabs, segmented control |
| App switcher | Tab switcher, task switcher | Overview screen showing open app instances/tabs as cards to switch between or close | Multi-window/multi-tab apps and browsers, or OS-level recent-apps view | Single-instance apps with no concept of multiple open contexts | Grid of cards, swipe-to-close | Browser tab strip; custom equivalent | OS app switcher (system-level, not in-app) | OS recent-apps screen (system-level) | Tab bar (in-page), window list menu |
