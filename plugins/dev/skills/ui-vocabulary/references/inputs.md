# Inputs

Controls for entering or choosing a value. See `selection.md` for
on/off and pick-one/many controls (checkbox, radio, switch, chips).

| Name | Also called | What it is | Use when | Avoid when | Variants/states | Web (HTML/ARIA, shadcn/Radix) | iOS (SwiftUI) | Android (Compose/Material) | Alternatives |
|---|---|---|---|---|---|---|---|---|---|
| Text field | Text input, form field | Single-line box for free-text entry | Short free-form values (name, email, address line) | Long-form text, or value is one of a known set | Default, focused, error, disabled, with label/helper/prefix-suffix icon | `<input type=text>`; shadcn `Input` | `TextField` | `TextField`/`OutlinedTextField` (M3) | Combobox (constrained), select |
| Textarea | Multi-line text field | Resizable multi-line box for longer free text | Comments, descriptions, messages | Single short value | Auto-growing, fixed-height, character counter | `<textarea>`; shadcn `Textarea` | `TextEditor` | `TextField(singleLine=false)` | Rich text editor |
| Select | Dropdown, picker (native) | Closed list of options, one collapses into a trigger | Small-to-medium fixed option set, low screen space | Options benefit from search, or list is long | Native vs. custom-styled, grouped options | `<select>`; shadcn `Select` (Radix) | `Picker(.menu)` | `ExposedDropdownMenuBox` (M3) | Radio group, combobox, segmented control |
| Combobox | Autocomplete, searchable select, typeahead | Text field + filtered dropdown list combined | Large option sets, or user may type a near-match | Small fixed set (≤ ~7), where a plain select is simpler | Single/multi-select, async/remote options, "create new" option | ARIA `combobox`; shadcn `Combobox` (Radix Popover+Command) | Custom (`TextField` + `List`) | Custom (`TextField` + `DropdownMenu`) | Select, tag input, search field |
| Search field | Search box, search bar | Text input styled/behaviorally specialized for search queries | Any content the user searches/filters by keyword | — | With live suggestions, recent searches, voice input, scoped filters | `<input type=search>`, `role=searchbox` | `.searchable()` | `SearchBar` (M3) | Combobox, filter panel |
| Date picker | Calendar picker, date input | Control to choose a single date, usually via calendar UI | Selecting one date (birthday, deadline) | Selecting a date range, or fast relative entry ("in 3 days") is enough | Inline calendar vs. popover, native `<input type=date>` | `<input type=date>`; shadcn `Calendar`+`Popover` | `DatePicker` | `DatePicker`/`DatePickerDialog` (M3) | Date range picker, relative-date shortcuts |
| Date range picker | Range calendar | Control to choose a start and end date together | Bookings, reports, filters over a period | Single date needed | Two-calendar, presets ("last 7 days") | Custom (no native HTML el.) | Custom dual `DatePicker` | `DateRangePicker` (M3) | Two separate date pickers, preset chip list |
| Time picker | Time input | Control to choose a time of day | Scheduling, alarms, reminders | — | Wheel/spinner, clock-face dial, text entry | `<input type=time>` | `DatePicker(.hourAndMinute)` | `TimePicker` (M3, dial or input) | Duration/stepper input |
| Slider | Range slider (single value) | Draggable handle on a track selecting a value in a range | Approximate numeric value where relative position matters more than exact typing | Precision-critical values, or value has no meaningful "range" | Single handle, range (two handles), stepped/discrete, with value label | `<input type=range>`; shadcn `Slider` (Radix) | `Slider` | `Slider`/`RangeSlider` (M3) | Number input, stepper |
| Number stepper | Number input, increment/decrement, quantity selector | Numeric field with +/− controls for discrete steps | Small-range integer values (quantity, count) | Large/continuous ranges | Inline +/− buttons, long-press to accelerate | `<input type=number>` + custom buttons | `Stepper` | Custom `Row` of `IconButton`s | Slider, plain number field |
| OTP input | PIN input, verification code field | Row of single-character boxes for a one-time code | SMS/email verification codes, 2FA | Any other text entry | Auto-advance per digit, paste-fills-all | Custom (segmented `<input>`s); shadcn `InputOTP` | Custom `TextField` row + `.oneTimeCode` | Custom `Row<TextField>` | Single text field with autofill |
| Tag input | Chip input, token field | Text field that turns entries into removable chips/tokens | Multi-value free entry (emails, keywords, labels) | Single value, or fixed option list (use multi-select instead) | Free-text tags vs. constrained-to-list, paste-splitting | Custom (`<input>` + chip list); shadcn `TagInput`-style patterns | Custom `TextField` + `FlowLayout` of chips | Custom `TextField` + `FlowRow` of `InputChip` | Multi-select combobox, filter chip group |
| Color picker | Color input, swatch picker | Control to choose a color value | Theme/brand customization, drawing tools | Fixed palette is preferable (use swatch/segmented instead) | Swatch grid, hue/sat/lightness picker, hex text entry, eyedropper | `<input type=color>` | `ColorPicker` | Custom (no native M3 component) | Swatch selector (fixed palette) |
| File upload | File picker, dropzone | Control to select/attach one or more files | Attaching documents, images, media | — | Click-to-browse, drag-and-drop dropzone, with preview/progress | `<input type=file>`; drag-drop `<div>` | `PhotosPicker`, `.fileImporter` | `ActivityResultContracts.GetContent`, custom dropzone | Camera capture, paste-from-clipboard |
| Rating input | Star rating, review score input | Control to select a discrete score, usually visual (stars/hearts) | Reviews, feedback, satisfaction scores | Fine-grained or continuous values | Stars, numeric scale, emoji scale, half-steps | Custom (`role=radiogroup` of stars) | Custom `HStack` of `Image`/`Button` | Custom `Row` of `Icon` | Segmented control, NPS-style number scale |
| Currency/amount input | Money field | Text field specialized for monetary amounts | Prices, budgets, transfers | — | Currency symbol prefix, thousands separators, decimal masking | `<input type=text inputmode=decimal>` + formatting | `TextField` + `.keyboardType(.decimalPad)` | `TextField` + `KeyboardType.Number` | Stepper (for small fixed increments) |
| Phone number input | Tel input | Text field specialized for phone numbers, often with country code | Sign-up, contact forms | — | Country-code select combined, auto-formatting | `<input type=tel>` | `TextField` + `.keyboardType(.phonePad)` | `TextField` + `KeyboardType.Phone` | Plain text field (low-stakes forms) |
| Input mask | Formatted input | Text field that auto-formats input to a fixed pattern (card number, date) | Structured values with a known format users benefit from seeing as they type | Free-form or highly variable-length values | Static mask, dynamic mask | Custom JS mask libraries | Custom `TextField` formatter | Custom `VisualTransformation` (Compose) | Plain field + inline validation message |
| Password field | Password input | Text field that masks entered characters, usually with a show/hide toggle | Entering secrets (passwords, PINs typed as text) | Non-secret values | Show/hide toggle, strength meter | `<input type=password>` | `SecureField` | `TextField` + `PasswordVisualTransformation` | PIN/OTP input (fixed-length codes) |
| Rich text editor | WYSIWYG editor | Multi-line text input supporting inline formatting (bold, lists, links) via a toolbar | Content authoring where formatting matters (posts, descriptions, docs) | Plain short-form text (use a textarea) | Toolbar vs. floating/bubble menu, markdown shortcuts | `contenteditable` + libs (Tiptap, Lexical); shadcn editor patterns | `TextEditor` + `AttributedString`, or 3rd-party | Compose `BasicTextField` + rich-text libs | Textarea (plain text), markdown field with preview |
| Voice input | Speech-to-text field, dictation | Control letting the user speak instead of type, transcribing to text | Hands-free or fast entry, accessibility | Environments where audio input is impractical (noisy, silence-required) | Push-to-talk vs. continuous, live transcript preview | Web Speech API mic button | System dictation via keyboard mic | `SpeechRecognizer` mic button | Plain text field |
| Signature pad | Signature capture | Canvas control capturing a hand-drawn signature via touch/mouse/stylus | Signing agreements, proof-of-delivery, forms requiring a signature | Formal e-signature with legal audit trail (use a dedicated e-sign flow) | Draw-to-sign, clear/retry, stroke smoothing | `<canvas>` + pointer events | `Canvas`/`PencilKit` | Compose `Canvas` + pointer input | Typed-name-as-signature field, e-signature provider embed |
