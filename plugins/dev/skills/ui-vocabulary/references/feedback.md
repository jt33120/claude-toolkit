# Feedback

Communicating status, progress, and outcomes to the user. Toast, snackbar,
and notification banner are transient/overlay feedback — full entries live
in `overlays.md` to avoid duplication; this file covers the rest.

| Name | Also called | What it is | Use when | Avoid when | Variants/states | Web (HTML/ARIA, shadcn/Radix) | iOS (SwiftUI) | Android (Compose/Material) | Alternatives |
|---|---|---|---|---|---|---|---|---|---|
| Alert / callout | Inline alert, notice box | Static, inline block highlighting important info within the page flow | Contextual info/warning tied to a specific section of content | Transient status (use toast), or page-wide status (use banner) | Info/success/warning/error tone, with icon, dismissible | `role=alert`/`region`; shadcn `Alert` | Custom styled `View`/`Label` | `Card`/`Surface` styled as alert (no dedicated M3 widget) | Banner, tooltip (for brief hints) |
| Inline validation | Field error message, helper text | Message shown directly under/near a form field about its current validity | Real-time or on-submit feedback tied to one specific field | General page-level errors (use banner/alert) | Error, warning, success (valid) states; live vs. on-blur/submit | `aria-describedby`/`aria-invalid`; shadcn form message | `Text` below `TextField`, `.foregroundStyle` | `supportingText` on `TextField` (M3) | Alert/callout, disabling submit with summary |
| Progress bar | Linear progress indicator | Horizontal bar showing determinate (or indeterminate) completion of a task | Task with a measurable duration/portion complete (upload, install) | Instant or unknown-length actions with no meaningful fraction | Determinate vs. indeterminate, buffered, with % label | `<progress>`, `role=progressbar`; shadcn `Progress` | `ProgressView(value:)` | `LinearProgressIndicator` (M3) | Spinner, skeleton, progress ring |
| Progress ring | Circular progress indicator | Circular version of a progress bar | Compact space (buttons, avatars), or app-wide loading | Long linear processes where a bar reads clearer | Determinate vs. indeterminate | `role=progressbar` styled circular; shadcn `Progress` (circular variant) | `ProgressView(value:)` circular style | `CircularProgressIndicator` (M3) | Progress bar, spinner |
| Spinner | Loading indicator, activity indicator | Indeterminate rotating indicator meaning "working, no known duration" | Short, unpredictable-length waits | Waits long enough that a skeleton better sets expectations | Small inline vs. full-view overlay | `role=status` + animated SVG/CSS; shadcn `Spinner`/`Loader` icon | `ProgressView()` (indeterminate) | `CircularProgressIndicator` (indeterminate, M3) | Skeleton, progress bar |
| Skeleton | Skeleton screen, placeholder loader, shimmer | Static/animated placeholder shapes mimicking the eventual content layout | Predictable content layout during initial load, to reduce perceived wait | Very short loads (a spinner is simpler), or totally unknown layout | Shimmer animation, matching text/image/card shapes | Custom CSS/`aria-busy`; shadcn `Skeleton` | Custom `View` + `.redacted(reason: .placeholder)` | Custom `Box` + shimmer `Modifier` | Spinner, progressive content reveal |
| Empty state | Zero state, blank slate | Illustrated/text placeholder shown when a list/view has no content yet | First use of a feature, or a filtered view with zero results | Content exists but is loading (use skeleton) | With CTA to create first item, with illustration, search-no-results variant | Custom composed region | Custom `ContentUnavailableView` | Custom composed `Column` | Onboarding tooltip, guided empty-state CTA |
| Error state | Error screen, failure state | Full-view or section replacement shown when content fails to load | A request/action fails and there's nothing to show instead | Field-level issues (use inline validation) | Retry button, error illustration, offline-specific variant | Custom composed region | Custom `ContentUnavailableView` | Custom composed `Column` | Inline alert (partial failure), toast (transient failure) |
| Badge | Count badge, notification dot (with number) | Small label overlaying/attached to an element showing a count or short status | Unread counts, new-item indicators, status labels on avatars/icons | Long text (use a chip/tag instead) | Numeric, dot-only, text label, positioned corner overlay | `<span>` styled; shadcn `Badge` | `.badge()` modifier | `Badge` (M3) | Status dot, chip |
| Status dot | Presence indicator, online indicator | Small colored dot signaling a state (online/away/error) without text | Compact presence/health signal attached to an avatar or list row | Ambiguous states needing a label (add text or use a badge) | Color-coded (online/away/offline/error), pulsing for "live" | `<span>` styled circle + `aria-label` | Small `Circle()` overlay | Small `Box` circle overlay | Badge, colored chip |
| Confirmation (feedback) | Success message, "saved" indicator | Brief positive acknowledgment that an action completed successfully | After a save/submit/completion, low-stakes | Actions needing the user to review results (show the result itself instead) | Inline checkmark, toast, button state change ("Saved ✓") | `role=status`; shadcn `Toast`/inline check icon | `.overlay` checkmark, haptic feedback | `Snackbar` or inline check icon | Toast, snackbar, button loading→success state |
| Loading button | Button loading state, in-progress button | A button that replaces its label with a spinner and disables itself while its action is pending | Any button-triggered async action (submit, save), to prevent duplicate taps and show progress | Actions that resolve instantly | Spinner-replaces-label, spinner-beside-label, success flash on complete | `disabled` + inline spinner; shadcn `Button` loading pattern | `Button` + `ProgressView` overlay, `.disabled()` | `Button` + `CircularProgressIndicator`, `enabled=false` | Full-page spinner, progress bar |
| Offline indicator | Connectivity banner, no-connection state | Persistent signal (banner or icon) shown when the app detects no network connection | Apps where actions can silently fail without connectivity | Apps that work fully offline by design | Banner, status-bar tint, disabled-action tooltips explaining why | `navigator.onLine` + `role=alert` banner | `NWPathMonitor` + banner `View` | `ConnectivityManager` + banner `Composable` | Toast on action failure (reactive instead of persistent) |
