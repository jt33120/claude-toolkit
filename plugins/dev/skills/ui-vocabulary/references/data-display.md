# Data display

Presenting collections of content or data.

| Name | Also called | What it is | Use when | Avoid when | Variants/states | Web (HTML/ARIA, shadcn/Radix) | iOS (SwiftUI) | Android (Compose/Material) | Alternatives |
|---|---|---|---|---|---|---|---|---|---|
| Table | Data table | Rows/columns of structured data with headers | Comparing structured records across consistent fields | Unstructured or highly variable-shape items (use a list/card grid) | Sortable headers, sticky header, striped, dense | `<table>`; shadcn `Table` | `Table` (iPadOS/macOS) | Custom `LazyColumn` grid layout | List, data grid, card grid |
| Data grid | Spreadsheet grid, editable grid | Table with per-cell interaction: sorting, filtering, inline editing, resizing | Large datasets needing power-user manipulation (admin tools, spreadsheets) | Simple read-only display (a plain table is lighter) | Virtualized rows, column pinning, cell editing, grouping | Custom/3rd-party (AG Grid, TanStack Table) | Custom (rare; usually a `Table`) | Custom (rare; usually `LazyColumn`) | Table, kanban (for status-grouped data) |
| List | List view | Vertical sequence of rows, each usually one item | Simple, scannable collections (settings, contacts, messages) | Data needing column comparison (use a table) | Single-line, two-line, with leading/trailing icons, sectioned | `<ul>/<li>`; shadcn nothing specific (composed) | `List` | `LazyColumn` + `ListItem` (M3) | Table, card grid, grid list |
| Card | Content card | Self-contained container grouping related content (image, title, meta, actions) | Browsable collections where each item deserves visual weight (products, articles) | Dense data better scanned as rows (use a table/list) | Elevated, outlined, filled (M3), horizontal vs. vertical | `<article>` styled `<div>`; shadcn `Card` | Custom `VStack` in `GroupBox`/styled container | `Card`/`ElevatedCard`/`OutlinedCard` (M3) | List row, table row |
| Accordion | Expandable panel group | Vertically stacked headers that expand/collapse to reveal content, usually one-open-at-a-time | Progressive disclosure of grouped content (FAQs, settings sections) | Content the user needs to compare simultaneously (keep expanded) | Single-open vs. multi-open, with icons | `<details>/<summary>`; shadcn `Accordion` (Radix) | `DisclosureGroup` | Custom expand/collapse `Column` + `AnimatedVisibility` | Collapsible (single item), tabs |
| Collapsible | Disclosure, expand/collapse | Single show/hide toggle for one block of content (accordion's single-item building block) | One optional/secondary block of content | Multiple related sections (use accordion for the group) | Chevron indicator, animated height | `<details>`; shadcn `Collapsible` (Radix) | `DisclosureGroup` (single) | `AnimatedVisibility` + toggle | Accordion, "show more" text link |
| Tree view | Tree, hierarchical list | Nested, expandable list representing a hierarchy (folders, org charts) | Data with parent-child nesting the user navigates | Flat data (use a plain list) | Multi-select with checkboxes, drag-to-reorder, lazy-loaded nodes | `role=tree`/`treeitem`; shadcn `Tree` (community) | Custom recursive `DisclosureGroup` | Custom recursive `LazyColumn` | Nested accordion, breadcrumb + flat list |
| Timeline | Activity feed, event log | Vertically ordered sequence of events/steps with connecting line and markers | Chronological history, order tracking, audit logs | Non-sequential content | Alternating sides, with icons/avatars per entry, collapsed/expanded | Custom composed list | Custom `VStack` with connector `Shape` | Custom `Column` with connector `Canvas` | Stepper (for a fixed known process), list |
| Avatar | Profile picture, user icon | Small image/initials representing a person or entity | Identifying a user/entity compactly (lists, headers, comments) | — | Image, initials fallback, icon fallback, shape (circle/square), size scale | `<img>` + fallback; shadcn `Avatar` (Radix) | `Image` clipped `.circle`, `AsyncImage` | `Image`/`Box` clipped `CircleShape` | Icon, initials badge |
| Avatar group | Avatar stack, facepile | Overlapping cluster of avatars representing multiple people, often with a "+N" overflow | Showing participants/collaborators compactly | Need to distinguish/interact with each individually (use a list) | Overlap direction, max-shown with overflow count | Custom composed `Avatar`s | Custom overlapping `HStack` | Custom overlapping `Row` | Full list of avatars with names |
| Stat tile | KPI card, metric card | Compact card showing one key number plus label and optional trend | Dashboards summarizing a single important metric | Detailed/multi-dimensional data (use a chart or table) | With trend arrow/sparkline, comparison to prior period | Custom composed `Card` | Custom `VStack` in card | Custom `Card` | Chart, table row with metric column |
| Chart | Graph, data visualization | Visual representation of quantitative data (bar, line, pie, area, scatter, etc.) | Showing trends, comparisons, distributions, or proportions | Precise individual values matter more than pattern (use a table) | Bar/line/area/pie/scatter/heatmap — pick per the `dataviz` skill, not here | SVG/Canvas libraries (D3, Recharts, Chart.js) | `Charts` framework (`Chart` view) | Compose `Canvas` or Vico/other chart libs | Stat tile (single value), table |
| Carousel | Slider (content), slideshow | Horizontally paged/scrollable sequence of items, usually one focal item at a time | Featured/promotional content, image galleries, limited space | Content the user needs to scan/compare all at once (use a grid) | Auto-advancing, dot/thumbnail indicators, swipe/drag | Custom scroll-snap `<div>`; shadcn `Carousel` (Embla) | `TabView(.page)` | `HorizontalPager` (Compose) | Grid, list, tabs |
| Calendar (display) | Date grid, month view | Grid laying out days/weeks/months for browsing or displaying events | Browsing dates or event-heavy schedules | Selecting a single date only (use date picker) | Month/week/day/agenda view, event dots/chips per day | Custom grid; shadcn `Calendar` (built on react-day-picker) | `Calendar`/custom grid `View` | Custom `LazyVerticalGrid` or Compose calendar libs | Agenda list, date picker |
| Kanban board | Task board, column board | Columns representing stages, with draggable cards moving between them | Workflow/status-based task tracking (to-do/in-progress/done) | Simple linear lists (use a plain list) | Swimlanes, WIP limits, collapsible columns | Custom (drag-drop libs) | Custom `HStack` of `List`s + drag gesture | Custom `Row` of `LazyColumn`s + drag-drop | List grouped by status, table with status column |
| Diff view | Comparison view, change view | Side-by-side or inline view highlighting differences between two versions | Code review, document revision comparison | Content with no prior version to compare | Side-by-side vs. inline/unified, line-level vs. word-level highlighting | Custom (e.g. diff libraries rendering `<pre>`) | Custom composed `Text` with highlight spans | Custom composed `Text` with highlight spans | Version history list, "track changes" annotations |
| Key-value list | Definition list, property list | Rows pairing a label with its value, for scanning discrete facts about one record | Summary/detail views of a single item's attributes (order details, profile info) | Data better compared across multiple records (use a table) | Two-column, stacked-on-mobile, with copy-to-clipboard per value | `<dl>/<dt>/<dd>`; composed `Grid`/list | Composed `LabeledContent` rows | Composed `Row` with label/value `Text` | Table (multi-record), card |
| Code block | Code snippet, syntax-highlighted block | Monospace block displaying source code, usually with syntax highlighting and copy action | Showing code, config, or command-line snippets | Prose content (use normal text) | Line numbers, language label, copy button, diff highlighting | `<pre><code>` + highlighter libs | `Text` (monospaced font) + custom highlighting | `Text` (monospace) + custom highlighting | Inline code span (for short snippets within text) |
| Feed | Activity stream, content feed | Continuously appended, reverse-chronological (usually) stream of heterogeneous items | Social/activity content that grows over time and mixes item types | Fixed, finite, homogeneous datasets (use a table/list) | Mixed card types, infinite-scroll-loaded, grouped-by-day | Composed list + infinite scroll | Composed `List` + `.onAppear` loading | Composed `LazyColumn` + paging | Timeline, table, paginated list |
