# Overlays

Content that floats above the page/screen: dialogs, sheets, menus, and
transient messages. See `feedback.md` for toast/snackbar as a feedback
mechanism (also listed here for the overlay-vs-overlay comparison).

| Name | Also called | What it is | Use when | Avoid when | Variants/states | Web (HTML/ARIA, shadcn/Radix) | iOS (SwiftUI) | Android (Compose/Material) | Alternatives |
|---|---|---|---|---|---|---|---|---|---|
| Dialog / modal | Modal window, popup dialog | Overlay that blocks interaction with the page behind it until dismissed | A focused task or decision that must interrupt the flow | Non-critical info (use inline/toast instead), or frequent low-stakes actions | With/without backdrop dismiss, sized (sm/md/lg/full) | `<dialog>`, `role=dialog`; shadcn `Dialog` (Radix) | `.sheet`, `.alert`, custom modal `View` | `AlertDialog`/`Dialog` (M3) | Drawer, inline expansion, dedicated page |
| Alert dialog | Confirmation dialog | Modal specialized for a single yes/no or destructive-action confirmation | Confirming a destructive or irreversible action (delete, discard) | Multi-field forms or long content (use full dialog) | Default vs. destructive-styled confirm button | `role=alertdialog`; shadcn `AlertDialog` (Radix) | `.alert(...)`, `.confirmationDialog` | `AlertDialog` (M3) | Undo (skip confirmation, allow undo instead) |
| Sheet | Bottom sheet, modal sheet | Panel that slides up from an edge (usually bottom), partially or fully covering the screen | Mobile-first contextual actions/content without leaving the screen | Desktop-dense forms (a dialog reads better) | Modal vs. non-modal (persistent), partial-height vs. full-height, draggable handle | Custom (`<dialog>` styled from bottom); shadcn `Sheet` (Radix Dialog variant) | `.sheet`, `.presentationDetents` | `ModalBottomSheet`/`BottomSheetScaffold` (M3) | Action sheet, drawer, popover |
| Drawer | Side panel, off-canvas panel | Panel that slides in from a screen edge, often non-modal or push-content | Auxiliary content/settings alongside main content (desktop/tablet) | Simple binary confirmation (use alert dialog) | Left/right/bottom, modal vs. persistent, resizable | shadcn `Drawer`/`Sheet` (Radix) | Custom side panel, `NavigationSplitView` | `ModalNavigationDrawer`, `DismissibleNavigationDrawer` | Sidebar, dialog, popover |
| Popover | Popup panel | Small, non-modal, anchored panel that appears near its trigger | Contextual controls/info tied to a specific element, dismissible by outside click | Content unrelated to a specific trigger element | With arrow/pointer, auto-repositioning | `popover` attr/`role=dialog`; shadcn `Popover` (Radix) | `.popover` | `Popup`, `DropdownMenu` (anchored) | Tooltip (info-only), dropdown menu (choice-only) |
| Tooltip | Hint bubble | Small text label shown on hover/focus/long-press, auto-dismisses | Brief supplementary explanation of an icon/control | Content needing interaction (use popover), or touch-primary UI (hover doesn't exist) | Hover-triggered (desktop), long-press (touch) | `role=tooltip`; shadcn `Tooltip` (Radix) | `.help()` (macOS), custom overlay on iOS | `PlainTooltip`/`RichTooltip` (M3) | Popover, inline helper text |
| Hover card | Preview card, rich tooltip | Larger, richer preview panel shown on hover over a link/reference | Preview of a person/link/item without full navigation (desktop) | Touch devices (no hover), or trivial content (use tooltip) | Delay-in/out timing, rich content (avatar, actions) | Custom; shadcn `HoverCard` (Radix) | No direct native equiv. (hover-first) | No direct native equiv. (hover-first) | Tooltip, popover, navigate-to-detail |
| Dropdown menu | Menu, select menu (action) | Anchored list of actions/commands triggered by a button | Grouped actions tied to a trigger (not data selection — that's a listbox/select) | Selecting a data value (use select/combobox) | With icons, submenus, checkable/radio items, separators | `role=menu`; shadcn `DropdownMenu` (Radix) | `Menu` | `DropdownMenu` (M3) | Overflow menu, context menu, action sheet |
| Context menu | Right-click menu | Menu triggered by right-click (desktop) or long-press (touch), anchored to the pointer | Contextual actions on a specific item without a visible trigger button | Actions that should always be visible/discoverable | Nested submenus, keyboard shortcuts shown | `contextmenu` event + `role=menu`; shadcn `ContextMenu` (Radix) | `.contextMenu` | Long-press + `DropdownMenu` | Dropdown menu (with visible trigger), action sheet |
| Action sheet | iOS action sheet | Mobile overlay listing actions as a stacked list, sliding from the bottom | A set of actions tied to a selection, mobile-native feel (esp. iOS) | Desktop web, or a single default action | Includes a distinct "Cancel", destructive-styled entries | Custom (rare on web) | `.confirmationDialog` (actionSheet style) | `ModalBottomSheet` with list items | Dropdown menu, bottom sheet |
| Lightbox | Image viewer overlay, media viewer | Full-screen (or near) overlay for viewing an enlarged image/media item | Viewing gallery images/media at full size | Content isn't primarily visual media | With pinch-zoom, swipe-between, thumbnails strip | Custom `<dialog>`; various libraries | Custom full-screen `View` with `.zoomable` | Custom full-screen `Dialog` with zoom/pager | Inline expanding image, dedicated media screen |
| Toast | Snack (rare) | Small, auto-dismissing message, usually with no or minimal action, often top or corner-positioned | Passive, low-priority status update that doesn't need user action | Errors requiring acknowledgement (use alert dialog or inline error) | Stacked, with icon, auto-timeout | ARIA `role=status`/`aria-live`; shadcn `Toast`/`Sonner` | Custom overlay (no native API); libraries | `Toast` (legacy) or custom `Snackbar`-style | Snackbar, banner, inline status |
| Snackbar | — | Brief bottom-anchored message, optionally with a single action (e.g. "Undo") | Confirming an action just taken, with an optional undo/retry | Info needing to persist or be re-referenced later | With action button, swipe-to-dismiss | Same pattern as toast on web (naming often merged) | Custom bottom overlay | `Snackbar` (M3) | Toast, banner, inline confirmation |
| Notification banner | Alert banner, page-level banner | Persistent, non-modal message bar spanning the top of a page/section | System-wide or page-wide status that should stay visible until dismissed/resolved | Transient confirmations (use toast/snackbar) | Info/warning/error/success tone, dismissible, with action link | `role=alert`/region; shadcn `Alert` used as banner | Custom banner `View` above content | `Banner`-style `Surface` (no dedicated M3 widget) | Toast, inline alert |
| Speed dial | FAB menu, expanding FAB | A floating action button that expands into several smaller action buttons on tap | A primary "create" action with a few closely related sub-actions | More than ~5 actions (use a menu), or actions unrelated to one primary action | Radial vs. linear stack, with labels, backdrop scrim on open | Composed `Button` + `Popover`/menu | Composed `Button` + overlay `VStack` | `FloatingActionButtonMenu` (M3 expressive) | Overflow menu, bottom sheet of actions |
