# Type : pub courte (non encore produit, à valider sur une première vidéo)

15 à 30 s pour faire connaître une offre ou un produit sur les réseaux. Deux méthodes possibles : description seule (concept original), ou 3 à 5 vidéos de référence dont on extrait le style sans le copier.

## Structure

| Temps | Rôle |
|---|---|
| 0–2 s | Accroche : une image ou une phrase qui arrête le défilement |
| 2–10 s | Promesse : ce que la personne y gagne |
| 10–22 s | Preuve : le produit en action, un chiffre, un avant / après |
| fin | Appel à l'action, logo, adresse |

## Règles propres au type

- Proposer 2 ou 3 pistes d'accroche à l'utilisateur avant d'écrire le reste.
- Une version par ratio (9:16 et 1:1) qui partagent les mêmes composants et diffèrent par les props.
- Sous-titres mot à mot : la plupart des vidéos sont vues sans le son.
- Musique plus présente que dans les autres types (≈ 16 dB sous la voix), mais jamais devant la voix.
- Aucune affirmation chiffrée sans source ; aucune promesse que l'offre ne tient pas.
