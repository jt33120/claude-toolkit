# Brief de poste, annonce, grille d'entretien, offre

## 1. Brief de poste {#brief}
Collecter avant de rediger :
- Titre du poste et mission en une phrase.
- 3-5 competences requises, chacune verifiable sur un CV ("a deploye une API en production"
  plutot que "bon esprit d'equipe").
- Fourchette de remuneration brute annuelle — demander un chiffre une fois, sinon omettre la
  section plutot que d'ecrire "competitif".
- Type de contrat envisage : CDI (par defaut), CDD (avec motif legal), ou freelance.
- Process d'entretien : nombre d'etapes, qui interviewe a chaque etape.

## 2. Structure de l'annonce
```
[Titre du poste]
[Mission en 2-3 phrases, orientee impact plutot que taches]

Ce que vous ferez
- [responsabilite 1]
- [responsabilite 2]

Ce qu'on cherche (verifiable sur un CV)
- [competence 1]
- [competence 2]

Remuneration : [chiffre ou fourchette]
Contrat : [CDI/CDD/freelance] — [lieu, remote/hybride]

Process : [nombre d'etapes]
```
Langage inclusif, honnete sur ce qui est difficile dans le poste (candidats mieux qualifies
s'auto-selectionnent). Exigences resserrees — chaque ligne est une raison de ne pas postuler.

## 3. Grille d'entretien
- 4-6 competences cles, une grille de notation 1/3/5 avec des ancrages concrets pour chaque
  niveau, specifiques au poste (jamais generiques).
- Pour chaque competence : 2-3 questions comportementales ("racontez-moi une fois ou...") et
  1-2 questions situationnelles ("comment reagiriez-vous si...").
- Repartir les competences entre les interviewers s'il y a plusieurs etapes, pour eviter les
  redondances.

## 4. Grille de tri des candidatures
- Trois paliers : must-have, should-have, nice-to-have — pondere sur 100, chaque critere note
  0-3, verifiable sur le dossier.
- Bande "ne peut etre evaluee" quand une information necessaire manque du CV — question au
  candidat plutot que rejet.
- Toujours citer l'element du CV/lettre qui justifie le score — un score sans citation est une
  impression, pas une evaluation.

## 5. Offre — structure
```
[Poste] — Offre

Remuneration : [brut annuel]
Date de debut : [date]
Type de contrat : [CDI/CDD], statut [cadre/non-cadre]
Periode d'essai : [duree, selon Code du travail et convention collective]
Convention collective : [a confirmer selon code APE]
Manager / responsable : [nom]

[Texte de l'offre, personnalise avec un element de l'entretien]

Cette offre est valable jusqu'au [date]. Merci de confirmer votre acceptation par ecrit.
```
Rappeler systematiquement : cette offre engage la SASU des lors qu'elle est ferme et precise —
a valider avec l'utilisateur avant tout envoi (voir `droit-travail.md#promesse`).

## 6. Messages de refus
Bienveillants, rapides, sans raison inventee. Exemple de structure :
```
Bonjour [Prenom],

Merci pour votre candidature au poste de [poste] et le temps consacre au process.

Apres reflexion, nous avons choisi de poursuivre avec un autre profil pour ce role. Ce n'est
pas une evaluation de votre parcours, la decision s'est jouee sur l'adequation specifique au
poste a ce moment.

Nous gardons votre profil et reviendrons vers vous si une opportunite correspondante se
presente.

Bonne continuation,
[Signature]
```
